# softlight · ใบเสนอราคา

โปรแกรมทำใบเสนอราคาระบบ HR Paper Mill — ดีไซน์ชุดเดียวกับแอป HR Paper Mill (Google Blog / Material 3, โหมดมืด, ใช้ได้ทุกขนาดจอ)

- เลือกแพ็กเกจสำเร็จรูป (ซื้อขาด / รายปี / รายเดือน · ราคาปกติหรือ Exclusive) แล้วแก้รายละเอียดได้
- ดูตัวอย่างกระดาษ A4 ทันที · พิมพ์หรือบันทึกเป็น PDF จากปุ่ม "พิมพ์ / PDF"
- บันทึกอัตโนมัติในเบราว์เซอร์เครื่องนี้ (ไม่ส่งข้อมูลออกไปที่ใด) · ย้ายเครื่องด้วย "ดาวน์โหลดข้อมูล / เปิดไฟล์ข้อมูล"

ราคามาตรฐานแก้ได้ที่ `PRICES` ด้านบนของ `js/app.js` · เอกสารแพ็กเกจสำหรับส่งลูกค้าอยู่ใน `docs/`
